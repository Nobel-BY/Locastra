# Locastra 0.9.0 无截图宣传片设计规范

## 产品简报与硬约束

- 发布渠道：B 站横版 1920×1080、抖音竖版 1080×1920。
- 时长：30 秒，30fps；无人声；输出带 BGM 和无 BGM（保留 SFX）两套。
- 核心受众：想在 Windows 上零命令行运行 GGUF 模型的中国大陆用户。
- 必须表达：多模型源、硬件适配、国内友好断点下载、本地推理与隐私、开源地址。
- 禁止出现：应用截图、浏览器页面、伪造的 Locastra 界面、私人路径或聊天正文。
- 结尾必须显示：github.com/Nobel-BY/Locastra。

## 执行决策

| 需求 | 执行 |
|---|---|
| 不出现应用截图 | 全片只使用品牌标、SVG 线路、几何节点、资源环、数据包和权重粒子 |
| 仍要看懂产品 | 每镜以可读大标题说明功能，以物理过程解释因果 |
| 手机端传播 | 主字幕有效字高不低于 56px，仓库 URL 为片尾主信息 |
| 高级感 | 深绿黑精密仪器风；青色只给状态与主角；不使用紫色霓虹、抖屏或群发扫光 |
| 无人声 | BGM 建立能量骨架，SFX 只钉汇聚、切换、落定等关键动作 |

## 视觉与动效 tokens

- 背景 #07100f；面板 #101d1b / #152522；细线 #28413d。
- 文字 #edf6f3；辅助 #9cb2ad；强调 #64f6e9 / #22cfc2。
- 字体：Segoe UI Variable / Microsoft YaHei；技术标注 Cascadia Code。
- 性格：专业、可靠、锋利；主入场约 21f；无手持抖动；全片画面级冲击不超过 2 次。
- 片头唯一主角为 Locastra 标志；片尾 URL 落定后至少 hold 1 秒。

## 功能到镜头映射

| 功能 | 镜头语法 | 依据 |
|---|---|---|
| 品牌建立 | 环轨汇聚 + 字距收束 | 单主体开场，保证品牌记忆 |
| 模型源 | bezier-source-converge-merge 适配 | 四个来源沿曲线进入 GGUF 统一入口 |
| 硬件适配 | 资源扫描环 + 规格卡错峰落位 | 用“扫描—判断—推荐”解释适配逻辑 |
| 稳定下载 | 三路下载线路 + 数据包 + 进度校验 | 直接表现来源切换、Range、.part 与 SHA256 |
| 本地推理 | unit-dot-swarm-regroup 动作语法适配 | 权重点群收拢成本地 GGUF 核心，再流式输出 |
| 开源收束 | logo-shrink-wordmark-lockup 适配 | 能量收束为标准品牌与真实 GitHub 地址 |

自定义实现不复刻任何既有页面；只借用镜头卡的运动语法。适配风险主要是横竖构图差异，使用两套响应式布局与逐画幅静帧验收控制。

## 音频

- BGM：Mixkit《House Vibez》— Lily J，来源与许可见 AUDIO-LICENSES.md。
- BGM 与 SFX 分离；bgm=false 时只关闭音乐，画面和 SFX 逐帧一致。
- SFX 用相对镜头起点的钉帧表；无游戏式提示音；片尾为过渡→impact→sparkle。
