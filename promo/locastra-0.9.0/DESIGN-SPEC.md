# Locastra 0.9.0 高密度无截图宣传片设计规范

## 产品简报与硬约束

- 渠道：B 站横版 1920×1080、抖音竖版 1080×1920。
- 时长：30 秒、30fps、无人声。
- 受众：希望在 Windows 上零命令行运行 GGUF 模型的中国大陆用户。
- 必须表达：ModelScope / Hugging Face 搜索入口、镜像下载备用、本地 GGUF 导入、硬件适配、量化推荐、国内友好断点下载、CUDA/Vulkan、本地隐私、离线对话、免费开源。
- 禁止出现：应用截图、浏览器页面、伪造产品 UI、私人路径或聊天正文。
- 片尾必须显示：`github.com/Nobel-BY/Locastra`。
- 用户明确要求只交付带背景音乐版本，因此本轮不生成无 BGM 版本；这是对 skill 默认双版本交付的显式覆盖。

## 联网调研结论

- TikTok 官方建议前 2 秒建立记忆、前 3 秒出现价值主张，并采用 Hook—Body—Close 结构。
- TikTok 官方建议字幕约 5–10 词/秒、9:16 安全区、声音开启、通过运动与文字持续制造刺激。
- Google ABCD 框架强调立即进入内容、紧凑节奏、高对比画面、品牌前置、单一明确 CTA。
- LinkedIn 官方分析显示前三秒 4 次以上场景变化与更高 CTR 相关；15–30 秒适合移动端产品广告。

据此放弃上一版“品牌慢开场 + 每功能 5 秒”的节奏，改为首 1 秒三连硬切、每 4 拍一个新结论、全片 14 个视觉段落。

## 视觉与动效

- 色板：深绿黑 `#050b0a`、月白 `#eef4ef`、品牌青 `#62f6e9`、警示橙 `#ff7657`、辅助黄 `#ffd166`。
- 字体：Segoe UI Variable / Microsoft YaHei；技术数字使用 Cascadia Code。
- 构图：巨型利益文案与数字为主角；技术标注只做辅助。
- 动效语法：采用 `trailer-bumper` 三连 9f 硬切；中段使用自定义并行能力矩阵；片尾使用静态品牌锁定，以可读 CTA 为优先。
- 禁止：全画面持续震动、无意义霓虹、廉价扫光、难读小字、连续交叉淡化。

## 音乐与节拍

- BGM：Mixkit《Cat Walk》— Arulo，约 130 BPM。
- 源曲节拍拟合：129.9969 BPM，`beat_zero=15.015949s`，拍间隔 `0.461549s`，最大残差 10.63ms，平均残差 3.45ms。
- 视频从源曲第 450 帧（15 秒）开始；渲后实测 AAC 输出链路产生约 39ms 统一偏移，因此切点使用独立 `OUTPUT_AUDIO_OFFSET=0.039s` 补偿，源分析值保持不变。
- 主要镜头均按每 4 拍切换：约 1.846 秒一段；首屏额外使用 9f×3 的速剪与 6f 纯黑喘息。
- 仅在开场、下载、隐私、免费开源与片尾使用克制 SFX；BGM 是主要节奏来源。
