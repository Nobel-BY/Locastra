# Locastra 0.9.0 宣传片设计规范

## 产品简报与执行约束

- 用途：B 站横版与抖音竖版的正式开源发布宣传片。
- 受众：想在 Windows 上零命令行部署本地 GGUF 模型的中国大陆用户。
- 核心卖点：国内友好模型发现与断点下载、硬件适配、一键 CUDA/Vulkan 加载、本机私密对话。
- 时长与语言：约 30 秒，简体中文，无人声；带 BGM 与无 BGM 两套交付。
- 数据口径：真实 Locastra 页面；模型名与硬件信息为公开/虚构演示状态，不展示私人路径、聊天正文或令牌。

## 视觉方向

选定“本地算力仪器”：不是通用赛博霓虹，而是深绿黑工作台、克制青色状态光、精密细线和原生 Windows 工具感。品牌调性为专业、可靠、锋利；能量轴中高、调性轴严肃。

- 背景：`#090f0f` / `#0e1514`
- 面板：`#161d1c` / `#1a2120`
- 文字：`#dde4e2`，辅助 `#bacac7`
- 强调：`#62f9ed`，强强调 `#3cdcd1`
- 警示：`#ffb956`
- 字体：Segoe UI Variable / Noto Sans SC / Microsoft YaHei；技术标签 Cascadia Code。
- 动效：主入场 21f，`cubic-bezier(0,0,0.2,1)`；无弹跳，落位后至少 15f 静止，品牌字标至少 30f 静止。
- 禁用：紫色大渐变、满屏星空、逐拍整屏缩放、手持抖动、群发扫光、低清 UI 纹理。

## 功能到镜头映射

| 功能 | 首选镜头卡 | 变体/依据 | 素材 |
|---|---|---|---|
| 品牌开场 | letterspace-materialize | 全字符同步结晶，Locastra 字标为唯一主角 | SVG 品牌标 + 文字 |
| 一体化模型中心 | wall-reveal-moves | wireframe-draw-on；真实页面由蓝图扫描实体化 | 真实模型中心截图 |
| 国内友好搜索与适配 | type-and-filter | 真人速度输入、结果收敛、真实槽位落定 | 搜索结果与版本选择截图 |
| 可恢复下载 | page-waterfall-wall | 改为三层差速传输卡流，强调持续稳定 | 真实下载管理截图 |
| 本机流式生成 | ai-stream-response | 语义块先出、状态与内容后跟、末尾完成态 | 真实对话截图 |
| 品牌收束 | logo-shrink-wordmark-lockup | 演出态几何能量收束为正式图标与字标 | Locastra 图标 |

参考实现均来自 video-shotcraft 对应配方卡与 demo。`type-and-filter` 只采用搜索交互段，不复用模板片的项目卡内容；`page-waterfall-wall` 改造成传输状态墙，保留差速反向与缓推语法。

## 分镜与帧级时间线（30fps）

| # | 时间 | 镜头 | 关键动效 |
|---|---|---|---|
| 1 | 0:00–0:03.5 | Locastra 字标结晶 | 同步描线、青色状态光、终态 hold |
| 2 | 0:03.5–0:08.0 | 模型中心首次亮相 | 线框描画→扫描实体化→轻推 |
| 3 | 0:08.0–0:13.0 | 搜索与硬件适配 | Qwen 输入、结果卡收敛、量化版本推近 |
| 4 | 0:13.0–0:17.0 | 断点下载 | 进度卡差速滑行，状态锁定 38% / 13 MB/s |
| 5 | 0:16.4–0:24.7 | 本机对话 | 对话页正视、思考折叠与安全示例输出语义块流入 |
| 6 | 0:24.3–0:30.0 | 本地闭环与发布 | 四个能力标签归拢，图标收束、LOCASTRA 与“现在开源”落定 |

接缝：1→2 暗场直航；2→3 元素穿窗；3→4 急刹甩镜；4→5 虚焦接力；5→6 暗场收束。全片仅 2 处画面级重音（模型中心实体化、片尾图标落定），不逐拍抖屏。

## 音频

- BGM：Mixkit《House Vibez》— Lily J，Mixkit Stock Music Free License，免署名可商用。
- BGM 在工程内以 0.56 增益混合并首尾淡入淡出；成片实测约 `-17.1 LUFS`、True Peak `-4.2 dBFS`；无人声。
- SFX：只使用已登记 URL 的 transition / impact / camera / light 素材；按动作峰值钉帧，避免合成 UI 游戏音。
- 同一时间线输出 `bgm=true` 与 `bgm=false` 两版；后者保留 SFX。

## 发布放行

方向与功能覆盖一致，自主自由创作模式放行进入最终素材采集和逐镜头实现。横版 1920×1080；竖版 1080×1920 使用同一叙事但重新布局字幕与截图，不做中心裁切。
