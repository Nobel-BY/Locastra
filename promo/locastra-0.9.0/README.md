# Locastra 0.9.0 Promo

使用 Remotion 生成的 30 秒开源发布宣传片工程，提供 B 站 16:9、抖音 9:16，以及带背景音乐和仅音效两套版本。

```powershell
npm install
npm run render:bilibili
npm run render:douyin
```

设计、节拍、素材许可与发布文案分别见 `DESIGN-SPEC.md`、`analysis/`、`AUDIO-LICENSES.md` 和 `POST-COPY.md`。真实应用截图位于 `public/ui/`，最终成片输出到 `out/`（不提交 Git）。
