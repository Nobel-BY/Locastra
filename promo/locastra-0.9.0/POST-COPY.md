我做了一个 Windows 本地 AI 应用：Locastra 0.9.0 开源发布

### 简介

Locastra 是一个面向 Windows 10/11 x64 的开源本地 AI 工作台，目标是让没有命令行经验的用户，也能完成“检测电脑 → 搜索 GGUF 模型 → 判断能否运行 → 国内友好下载 → 一键加载 → 本地对话”。

0.9.0 支持 ModelScope / Hugging Face 搜索、hf-mirror 镜像、断点续传、CUDA / Vulkan 运行组件、模型库、对话管理、本地资料、模型对比、MCP 工具、上下文自动总结与浅色 / 深色界面。

聊天与设置默认保存在本机，推理服务只监听 `127.0.0.1`。安装包目前未做商业代码签名，Windows SmartScreen 可能显示“未知发布者”，请从 GitHub Release 下载并核对 SHA-256。

项目地址：https://github.com/Nobel-BY/Locastra

下载地址：https://github.com/Nobel-BY/Locastra/releases/tag/v0.9.0
