# Locastra 0.9.0 发布说明

Locastra 0.9.0 是面向 Windows 10/11 x64 的公开测试版本，继续坚持本地优先、无需账号和中国大陆友好的 GGUF 下载体验。

## 主要更新

- 新增全局快速指令中心：按 `Ctrl+K` 搜索页面、对话、模型、项目和助手。
- 对话页新增模型选择器，可在当前工作流中直接加载和切换已安装模型。
- 模型库新增容量总览与批量管理，可只移出索引，也可永久删除文件释放空间。
- 修复分片 GGUF 删除不完整的问题：删除模型文件时会安全识别并删除同一分片组的全部常规文件。
- 设置页新增发布状态摘要，集中展示版本、隐私、模型资产和推理引擎状态。
- 延续 0.6–0.7 系列的界面动效、深浅主题、键盘焦点和减少动效适配。

## 隐私与安全

- 聊天、设置、模型索引和项目资料默认保存在本机。
- 推理服务仅监听 `127.0.0.1`；可选 API Token。
- 模型仓库内容按不可信数据处理，只接受 GGUF，不执行仓库脚本。
- 诊断包默认不包含聊天正文。
- 永久删除模型文件前会显示文件数量和预计释放空间，并要求再次确认。

## 已知说明

- 当前公开构建未附带商业代码签名证书，Windows 可能显示 SmartScreen 提示。
- 图片理解需要模型支持视觉输入，并配置相匹配的 `mmproj` GGUF。
- 语音输入依赖 Windows 已安装的离线语音识别包。
- 受限或私有模型仓库暂不支持令牌登录。
